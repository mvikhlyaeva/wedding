# 03 — Data Layer: Модели, Миграции, Seed

## Цель
Определить структуру базы данных, создать миграцию и заполнить тестовыми данными.

## Что реализовать

- Определить модели в `Models/`:
  - `Guest` — гость с уникальным кодом и именем
  - `Rsvp` — ответ гостя (придёт / не придёт, кол-во гостей, заметка)
- Добавить модели в `AppDbContext`
- Создать и применить миграцию
- Добавить seed-данные: 2–3 тестовых гостя с кодами (для разработки)

## Что НЕ фиксировать заранее
Конкретный список полей и их типы определяются здесь, при реализации.
Отталкиваться от минимума: что реально нужно форме RSVP.

## Критерии готовности

- `dotnet ef database update` проходит без ошибок
- В БД есть таблицы `Guests` и `Rsvps`
- Тестовые гости доступны через `AppDbContext` в коде
- Приложение стартует с уже накаченной БД
