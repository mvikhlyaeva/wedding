# 05 — Страница: Главная `/`

## Цель
Сверстать главную страницу с информацией о свадьбе. Без запросов к API — только статичный контент.

## Что реализовать

Секции (порядок и состав — на своё усмотрение при реализации):
- Имена и дата свадьбы — главный экран
- Место проведения (название, адрес)
- Программа дня / тайминг
- Как добраться (опционально)
- Контакты для вопросов (опционально)

Контент — заглушки / placeholder текст. Реальные данные заполнятся позже.

## Критерии готовности

- Страница открывается по `/`
- Все секции видны на мобильном экране (375px)
- Нет горизонтального скролла
- Выглядит опрятно даже с placeholder-текстом
