# 05 — Страница: Главная `/`

## Цель
Страница без кода — показывает информацию о свадьбе без персонализации и без RSVP-формы.
Точка входа для тех, кто открыл сайт без ссылки.

## Структура страницы

- Дата и время свадьбы
- Место (название, адрес)
- Программа / тайминг дня
- Как добраться (опционально)
- Контакты для вопросов (опционально)

Контент статичный — в коде, не из API. Без приветствия, без формы.

## Критерии готовности

- `/` открывается и показывает информацию о свадьбе
- Нет никакой персонализации и RSVP
