# Задача 08 — Редизайн: Pinterest-стиль по ТЗ

## Цель

Переписать визуальный дизайн свадебного лендинга в соответствии с ТЗ, составленным по анализу референсов из Pinterest. Результат должен выглядеть как работа живого дизайнера, а не AI-шаблон.

---

## Референсы

Пять Pinterest-карточек свадебных приглашений. Общее направление: органичный минимализм, тёплая премиальность, нейтральная основа + один акцентный цвет.

---

## Цветовая палитра

Обновить токены в `frontend/src/index.css`:

```css
--ivory:      #F5F0E7;   /* тёплый айвори, основной фон */
--champagne:  #C8B89A;   /* пудровый, делимитеры и иконки */
--sage:       #6B7A5E;   /* шалфей, акцентный цвет */
--text:       #2A2118;   /* почти чёрный, тёплый */
--muted:      #8A7D72;   /* приглушённый текст */
--line:       #DDD5C4;   /* тонкие линии */
```

Запрещено: золото, розовый неон, холодные серые, лавандовый.

---

## Типографика

Оставить Google Fonts: `Cormorant Garant` + `Jost`. Правила применения:

| Роль | Шрифт | Размер |
|------|-------|--------|
| Имена, hero-заголовок | Cormorant Garant Italic, 300 | clamp(3rem, 10vw, 5rem) |
| Секционные заголовки | Jost 400, uppercase, tracking 0.2em | 0.65rem |
| Тело, расписание | Cormorant Garant 300 | 1rem–1.1rem |
| Подписи, лейблы | Jost 300, uppercase, tracking 0.28em | 0.58rem |

## Структура страницы — `InvitePage`

### ① Hero-блок
- Фото пары full-bleed, высота `100svh`
- Градиент снизу: `rgba(0,0,0,0.5)` → transparent
- Имена крупным Cormorant Italic поверх — белые, снизу
- Дата мелко: `27 · 06 · 2026`
- Анимация: `heroReveal` (scale 1.04 → 1.0 + fadeIn, 1.8s)
- Никакой навигации и кнопок

### ② Текст приглашения
- Ботанический SVG-орнамент (уже есть, `BotanicalLine`)
- Имя гостя курсивом крупно
- 2–3 строки текста приглашения, serif light, цвет `--muted`
- Выравнивание по левому краю

### ③ Место и дата
Типографический блок:
- `ИЮНЬ` — маленький uppercase label
- `27` — огромное число, clamp(6rem, 20vw, 9rem)
- Адрес и ссылка на карту под числом
- Левосторонние угловые акценты через CSS background (уже есть)

### ④ Программа дня
Список с выравниванием:
```
16:00  —  Сбор гостей
17:30  —  Выездная регистрация
18:30  —  Начало банкета
22:00  —  Вынос торта
```
Время — `--sage` или Cormorant, событие — Jost light.
Альтернатива: сохранить текущий wave-schedule с сердечком — на усмотрение.

### ⑤ Дресс-код
Новый блок (добавить после деталей):
- Заголовок `ДРЕСС-КОД` uppercase
- 1–2 строки описания
- **Цветовые кружки** — 4–5 кружков палитры торжества:
  - `#E8E0D0` (айвори)
  - `#C8B89A` (пудра)
  - `#6B7A5E` (шалфей)
  - `#2A2118` (тёмный)
- HTML: `<div class="dress-swatch" style="--c: #6B7A5E"></div>`

```css
.dress-swatch {
  width: 32px;
  height: 32px;
  border-radius: 50%;
  background: var(--c);
  border: 1px solid rgba(0,0,0,0.08);
}
```

### ⑥ Фото-моменты
Минимум два фото пары размещаются между секциями (не в галерее):
- Одно: full-bleed стрип, высота 60vw, `max-height: 400px`
- Второе: портрет, выходит за один из краёв (`margin-right: -var(--pad-x)`)
- Фильтр: `saturate(0.85) brightness(1.01)` для единства с палитрой
- Анимация hover: `scale(1.03)`, 0.8s ease

### ⑦ RSVP-форма
Без изменений в логике. Визуальные правки:
- Кнопки attend: фон `--sage` в активном состоянии вместо `--champagne`
- Submit-кнопка: `border: 1px solid --sage`, hover — заливка `--sage`

### ⑧ Финальный экран
После RSVP добавить небольшой closing-блок:
- Текст «Будем рады вас видеть» — Cormorant Italic, 1.4rem
- Подпись: имена пары скриптом (просто курсивный Cormorant)
- Декоративный элемент: `♡` или ботаническая линия

## Анимации

| Триггер | Анимация | Параметры |
|---------|----------|-----------|
| Загрузка hero | scale 1.04→1 + fadeIn | 1.8s cubic-bezier |
| Секции при загрузке | fadeUp 16px, stagger | 0.7s, delays 0.05–0.56s |
| SVG-орнамент | stroke-dashoffset draw | 0.7s, стартует после hero |
| Hover кнопок | background fill | 0.3s |
| Hover фото | scale(1.03) | 0.8s ease |
