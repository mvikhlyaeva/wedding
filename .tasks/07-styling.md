# 07 — Стилизация: CSS, Mobile-First, Дизайн

## Цель
Придать сайту законченный, элегантный вид в соответствии с UI-правилами из CLAUDE.md.

## Что реализовать

**Базовые стили**
- CSS-переменные: цвета (2–3), шрифты, отступы
- Reset / normalize (минимальный, руками)
- Типографика: serif для заголовков, sans-serif для текста

**Layout**
- Mobile-first: базовая вёрстка под 375px, медиазапросы для wide
- Максимальная ширина контента ~680px, центрирование
- Достаточно воздуха между секциями

**Компоненты**
- Кнопки: тонкие, без скруглений-пузырей, с hover-состоянием
- Форма: лаконичные инпуты, без лишних декораций
- Разделители секций: тонкая линия или просто отступ

**Анимации**
- fade-in при загрузке страницы или появлении контента (если уместно)
- Никаких тяжёлых эффектов

## Критерии готовности

- Сайт выглядит корректно на 375px и 1280px
- Нет горизонтального скролла ни на одной странице
- Палитра сдержанная, не больше 3 цветов
- Кнопки и форма выглядят как часть единого дизайна
- Не использованы UI-библиотеки
