# 06 — Страница: Лендинг-приглашение `/:code`

## Цель
Персональный лендинг для конкретного гостя. Содержит приветствие, информацию о свадьбе
и RSVP-форму в конце. Гость получает ссылку вида `https://site.com/yana`.

## Структура страницы (сверху вниз)

### 1. Приветствие
- Обращение по имени: «Дорогая Яна» / «Дорогие Виктория и Дмитрий»
- Тёплый, личный текст-приглашение
- Имя берётся из `guest.name` — API возвращает полное отображаемое имя

### 2. Информация о свадьбе
- То же содержимое что на главной `/`
- Дата, место, программа, контакты

Контент статичный — в коде, не из API.

### 3. RSVP-форма (в конце страницы)
Для каждого человека в приглашении (`guest.persons`):
- Имя персоны
- Приду / Не приду (radio или кнопки)
- Есть ли ограничения в еде, аллергии? (textarea, необязательно)

Общее для всего приглашения:
- Заметка / пожелания (textarea, необязательно)
- Кнопка отправить

**Состояния формы:**
- Если `guest.rsvp === null` — форма пустая, POST при отправке
- Если `guest.rsvp` уже есть — форма заполнена текущими ответами, PUT при отправке + кнопка «Изменить ответ»
- После отправки — подтверждение на месте формы, без редиректа

## Состояния загрузки страницы

- Загрузка — нейтральный индикатор
- Код не найден — 404, показываем информацию о свадьбе без персонализации (как на главной)
- Загружено — полный лендинг

## Критерии готовности

- `/yana` загружает имя и показывает полный лендинг
- `/vd` показывает двух персон в форме
- `/` показывает только информацию о свадьбе
- Форма отправляется, ответ сохраняется в БД
- Повторный заход показывает заполненный ответ
- Изменение ответа работает через PUT
