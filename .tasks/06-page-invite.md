# 06 — Страница: Приглашение `/invite/:code`

## Цель
Реализовать персональную страницу гостя с обращением по имени и RSVP-формой.

## Что реализовать

**Загрузка данных**
- При открытии страницы — `GET /api/invite/:code`
- Состояния: загрузка / ошибка / не найден / загружен

**Персональное приглашение**
- Обращение по имени гостя
- Детали: дата, место (можно взять из констант, не из API)

**RSVP-форма**
- Поля определяются при реализации — минимум: приду / не приду
- Если гость уже отвечал — показать текущий ответ и кнопку "Изменить"
- После отправки — подтверждение (без редиректа)

**Логика**
- Новый ответ → POST `/api/rsvp`
- Изменение → PUT `/api/rsvp/:code`
- Обработка ошибок API: показать понятное сообщение, не ломать страницу

## Критерии готовности

- `/invite/ivan42` загружает имя Ивана с бэкенда
- `/invite/unknown` показывает страницу "приглашение не найдено"
- Форма отправляется, ответ сохраняется в БД
- Повторный заход показывает уже заполненный ответ
- Изменение ответа работает
