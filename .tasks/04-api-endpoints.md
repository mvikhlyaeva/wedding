# 04 — API: Эндпоинты Приглашения и RSVP

## Цель
Реализовать три эндпоинта, которые нужны фронтенду для работы персональной страницы и RSVP-формы.

## Что реализовать

**GET `/api/invite/:code`**
- Найти гостя по коду
- Вернуть имя, код и текущий RSVP (если уже есть)
- 404 если код не найден

**POST `/api/rsvp`**
- Принять ответ гостя (код + данные формы)
- Создать запись RSVP
- 400 если гость уже отвечал (предлагать PUT)

**PUT `/api/rsvp/:code`**
- Обновить существующий ответ
- 404 если ответа ещё нет

Валидация минимальная — только необходимые поля.
Возвращать понятные сообщения об ошибках.

## Критерии готовности

- Все три эндпоинта работают через curl / Postman
- GET с несуществующим кодом → 404
- POST дважды → 400 с понятным сообщением
- PUT обновляет запись в БД
- Ответы в JSON
